# BANKDOIT en Flutter

Desde la carpeta mobile, ejecuta `flutter pub get` y después `flutter devices` para ver los destinos disponibles.

- Web en Chrome: `flutter run -d chrome`
- Escritorio Windows: `flutter run -d windows`
- Android: conecta un teléfono con depuración USB o inicia un emulador, y ejecuta `flutter run -d ID` sustituyendo ID por el identificador del dispositivo.

La pantalla inicial muestra BANKDOIT. Para verificar el entorno de desarrollo, usa `flutter doctor`.
